# 미니 리필 스테이션 관리자 대시보드

React(CRA) 기반의 내부 운영자용 대시보드입니다. 즉각적인 액션 아이템, KPI, 스테이션/상품 관리, 매출 분석을 단일 화면에서 확인할 수 있도록 구성했습니다.

## 개발 환경

- React 18 + react-scripts 5
- Recharts (라인/에어리어 차트)

```bash
npm install
npm start   # http://localhost:3000
```

## 주요 섹션

1. **메인 대시보드**: 긴급 알림, KPI 카드, 7일 매출 추이, 인기 상품 Top5
2. **스테이션 관리**: 재고/상태 테이블, 임계치 강조, 디스펜서별 상세, 점검 로그
3. **상품 관리**: 리스트 테이블 + 등록/수정 폼(위생정보·이미지 업로드 포함)
4. **매출 분석**: 일/주/월 토글, 총매출·객단가·재구매 카드, 영역 차트 및 세부 표

모든 데이터는 목업 데이터이며 추후 API 연동 시 `src/data/mockData.js`를 대체하면 됩니다.
